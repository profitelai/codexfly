# GitHub Growth Review

Perform a focused GitHub-native growth review for Codexfly.

## Instructions

1. Prioritize repository description, topics, README opening section, contribution flow, onboarding friction, PR and issue templates, and social/share assets.
2. Check whether the repository clearly explains what the project is, who it is for, why it matters, and what a contributor should do next.
3. Focus on GitHub-native discoverability rather than generic website SEO.
4. Recommend concrete improvements for repo conversion: stars, forks, issues, discussions, contributions, and profile completeness.

## Output sections

- Summary
- Audience and repository intent
- Current conversion blockers
- Metadata and README recommendations
- Open-source onboarding recommendations
- Follow-up checks
