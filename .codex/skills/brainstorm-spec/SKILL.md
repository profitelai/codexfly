# Brainstorm Spec

Convert rough Codexfly ideas into a clear feature spec.

## Instructions

1. Anchor the spec to Codexfly's current product direction: project memory, multi-model continuation, research-before-coding, orchestration, and mission-control UX.
2. Write the output to `docs/specs/<slug>.md` when the user asks for a file-ready spec.
3. Make assumptions explicit.
4. Keep the spec decision-ready.

## Output sections

- Summary
- Problem
- Target user
- Goals
- Non-goals
- User flow
- Requirements
- Constraints
- Risks
- Open questions
- Recommended next steps
