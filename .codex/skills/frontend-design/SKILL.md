# Frontend Design

Define UI direction for Codexfly before implementation.

## Instructions

1. Follow Codexfly's design direction: simple on entry, cinematic in depth, clean enough for daily use, visually alive without noise.
2. Favor strong hierarchy, mission-control clarity, and original visuals.
3. Avoid generic AI dashboard clichés.
4. When useful, structure recommendations around `apps/web` and reusable elements in `packages/ui`.

## Output sections

- Screen or page goal
- Audience
- Information hierarchy
- Layout structure
- Motion and interaction notes
- Components needed
- States: loading, empty, error, success
- Accessibility notes
- Implementation notes
