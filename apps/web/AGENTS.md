# Web App Instructions

When working in `apps/web`:

- Follow the mission-control design direction from the repository README
- Prefer strong information hierarchy over decorative clutter
- Use motion to clarify status, transitions, and pipeline flow
- Keep accessibility and readability intact
- Avoid generic AI dashboard tropes

Before major UI implementation:
- define audience
- define page purpose
- define visual direction
- define success, empty, loading, and error states
