# Design System

## Principles

- simple surface, powerful depth
- cinematic, not cluttered
- original, not derivative
- motion should support clarity
- information density should stay readable

## Visual Direction

- dark base palette
- glass and glow accents
- soft grid or depth layers
- restrained neon highlights
- subtle particles and ripple interactions

## Interface Modes

### Project Launcher

Clean and minimal.

Purpose:

- create a task
- continue a session
- open a project
- enter mission control

### Mission Control

Dense but structured.

Should include:

- central progress state
- agent activity panel
- project memory panel
- timeline of actions
- usage and cost insights

## Motion Rules

- use motion to indicate system state, not decoration only
- prefer calm loops over noisy effects
- make critical state changes obvious
- avoid heavy animation that hurts usability
