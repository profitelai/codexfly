# Vision

Codexfly exists to make AI-assisted software work persistent, structured, and improvable.

## Problem

AI coding sessions are often fragmented:

- context gets lost
- good prompts are not reused
- multiple models cannot continue from the same state cleanly
- session history is hard to search and compare
- usage cost grows without enough visibility

## Vision

Codexfly should become a project operating system for AI-assisted development.

It should help teams:

- remember the project, not just the chat
- route work to the right model or agent
- analyze why a workflow succeeded or failed
- improve future prompts using past outcomes
- manage AI work from a clear command-center dashboard
- reuse high-value workflow modules across repositories without repeating the same prompt scaffolding
- reduce token waste by loading only the instructions and skills a project actually needs

## Product Identity

Codexfly is not:

- just a transcript viewer
- just an observability tool
- just another coding agent wrapper

Codexfly is:

- a persistent AI project workspace
- a prompt intelligence system
- an agent orchestration layer
- a cinematic mission-control experience for software delivery
- a reusable skill and memory layer for multi-project AI development
