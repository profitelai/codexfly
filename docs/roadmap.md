# Roadmap

## Phase 1: Open-Source Foundation

- establish repository structure
- publish product vision
- define architecture
- define contribution workflow
- create community and issue templates
- create repo-native skill packs and project skill loaders

## Phase 2: Core Project Memory

- create project entity model
- implement session ingestion model
- define raw events schema
- define structured project memory schema
- build distilled handoff brief generation

## Phase 3: Session Replay and Search

- searchable session list
- session timeline view
- event replay
- basic project summaries

## Phase 4: Prompt Intelligence

- original prompt vs improved prompt
- prompt scoring
- failure analysis
- recommendations for better task framing

## Phase 5: Agent Workflows

- Project Manager agent
- Research-first workflow
- Codex execution agent
- Review agent

## Phase 6: Usage and Cost Analytics

- token and cost tracking
- limit tracking
- efficiency dashboards
- high-usage diagnostics
- skill-pack effectiveness and prompt-reuse analysis

## Phase 7: Mission-Control UX

- project launcher
- command-center dashboard
- live progress pipeline
- agent activity panel
- project memory panel

## Phase 8: Multi-Model Continuation

- shared project context across models
- model handoff summaries
- task routing by model type
- continuation from latest verified checkpoint
